# Online Remote Assessment Architecture: Token-Based Mobile Screening Engine

## Problem Statement
How might we enable candidates to complete the PGE recruitment assessment remotely on their own mobile devices using a secure 6-digit One-Time Token (PIN), applying a split-guardrail model (relaxed for psychometrics, strictly timed & anti-cheat for cognitive logic), while autosaving progress in real-time and feeding verified scorecards directly into the recruiter's talent pool?

---

## Recommended Direction: The "Dual-Paced Tokenized Mobile Engine"

A dedicated, privacy-isolated candidate assessment web experience accessed via a universal portal (`pge-talentpool.web.app/test` or `test.html`) protected by a 6-digit PIN generated by HR, featuring two distinct testing modes:

### 1. Token & Access Lifecycle (6-Digit One-Time PIN)

#### A. Generation by HR:
- Inside the Candidate Profile Modal or Drawer in `index.html`, add a button:
  **`🔑 Buat PIN Tes Online`**
- System generates a cryptographically random 6-digit PIN (e.g., `839-214`), valid for 24 hours.
- Saves token metadata in Firebase RTDB / Appwrite:
  ```json
  "/assessmentTokens/839214": {
    "talentId": "PGE-001",
    "name": "Lia Ana Pratama",
    "role": "Freelance Content Creator",
    "createdAt": 1789710000000,
    "expiresAt": 1789796400000,
    "status": "active", // "active" | "in_progress" | "completed" | "expired"
    "currentQuestion": 0,
    "tabSwitchCount": 0,
    "answers": {}
  }
  ```
- Generates a **1-Click WhatsApp Invitation Template**:
  > *"Halo Kak Lia Ana Pratama, selamat Anda lolos ke tahap asesmen online PGE Talent Pool! Silakan akses portal tes melalui HP/laptop Anda di: https://pge-talentpool.web.app/test dengan memasukkan PIN akses Anda: 839-214 (Aktif selama 24 jam). Pastikan berada di tempat yang tenang."*

#### B. Candidate Entry & Isolation:
- Candidate visits `https://pge-talentpool.web.app/test`.
- They see a minimalist, branded welcoming PIN input screen.
- Upon entering `839-214`, the engine fetches *only* their specific record.
- **Absolute Privacy**: The candidate never receives or queries other candidates' data.

### 2. The Split Testing Methodology (Separated Guardrails)

#### **Section 1: Kepribadian & Karakter Kerja (Big Five & DISC)**
- **Pacing**: **Fleksibel & Santai**. Tidak ada countdown timer yang menekan.
- **Rationale**: Psikotes tidak memiliki jawaban "benar" atau "salah". Tekanan waktu justru memicu stres berlebih yang mengaburkan gambaran karakter asli.
- **Audit Tersembunyi (Expert Psychometric Checks)**:
  - **Click-Speed Audit**: Menandai jika kandidat mengklik jawaban secara serampangan (< 1.0 detik per pertanyaan secara beruntun).
  - **Inconsistency Audit**: Mengorelasikan pertanyaan bernada serupa (misal item Conscientiousness positif vs item reverse-coded). Jika hasilnya kontradiktif, sistem memberikan flag *"Inkonsistensi Jawaban Tinggi (Potensi Faking Good)"* pada dossier HR.

#### **Section 2: Logika Komersial & Penalaran Kognitif (Aptitude & Frexor)**
- **Pacing**: **Strict Countdown Timer (45–60 detik per soal)**.
- **Anti-Cheat Suite**:
  1. **Tab-Switch & Blur Detection**:
     - Menggunakan `document.addEventListener('visibilitychange')` dan `window.onblur`.
     - Jika kandidat membuka tab lain (misal untuk copy-paste ke ChatGPT atau Google), layar langsung memunculkan modal peringatan:
       > *"⚠️ Peringatan (1/3): Anda terdeteksi meninggalkan halaman tes. Mohon tetap berada di layar hingga soal selesai."*
     - Total pelanggaran dicatat di laporan HR (`tabSwitchViolations: 2`).
  2. **Clipboard & Copy Protection**:
     - `oncopy="return false;"`, `onpaste="return false;"`, `user-select: none`.
     - Teks soal tidak dapat disalin dengan mudah ke clipboard.
  3. **Auto-Advance pada Time-Out**:
     - Jika waktu habis sebelum kandidat menjawab, sistem otomatis menyimpan jawaban kosong dan maju ke soal berikutnya.

---

### 3. Reliability & Candidate Experience (Mobile-First)

#### **A. Real-Time Cloud Autosave**:
- Setiap kali kandidat memilih opsi jawaban, payload kecil dikirim ke Firebase RTDB:
  ```json
  rtdb.ref('/assessmentTokens/' + pin + '/answers/' + questionId).set(answerValue);
  ```
- Disertai backup `localStorage` di browser HP kandidat.
- **Zero Data Loss Guarantee**: Jika browser tertutup, sinyal HP putus di jalan, atau baterai habis, kandidat cukup membuka kembali link dan memasukkan PIN yang sama — sistem langsung melompat ke soal terakhir yang belum dijawab.

#### **B. Thumb-Zone Mobile UX**:
- Target tombol radio minimal **48px tinggi** dengan radius melengkung halus dan feedback visual instan saat disentuh.
- Progress bar di bagian atas menampilkan status penyelesaian yang transparan.
- Smooth transition: Setelah memilih opsi pada psikotes, layar otomatis bergerak halus (*auto-advance*) ke soal berikutnya tanpa perlu menekan tombol "Next" berulang kali.

#### **C. Completion Screen (Employer Branding Perk)**:
- Setelah menekan tombol *"Kirim Jawaban Final"*:
  - PIN langsung dikunci permanen (`status: 'completed'`).
  - Halaman kandidat menampilkan ucapan terima kasih profesional.
  - Memberikan hadiah apresiasi berupa **Mini Infografis Karakter Kerja** (misal: *"Gaya dominan Anda adalah Kolaborator Kreatif (High Influence & Agreeableness)"*) dengan 3 tips pengembangan karier.
  - **Kerahasiaan Terjaga**: Skor logika kognitif dan kunci jawaban tetap dirahasiakan 100% dari kandidat agar bank soal tidak bocor.

## Key Assumptions to Validate
- [ ] Kandidat di berbagai tipe smartphone (Android entry-level s/d iPhone) dapat menjalankan timer SVG & JavaScript tanpa lag baterai.
- [ ] Penggunaan 6-digit PIN numerik lebih ramah dan minim typo dibanding token alfanumerik panjang (misal `a8f9-2c71`).
- [ ] Deteksi tab-switch tidak memicu *false positive* jika kandidat hanya menerima notifikasi pesan singkat di HP.

---

## MVP Scope (Tahap Implementasi Mendatang)
1. **Universal Route**: Halaman web ringan `public/test.html` (atau `/test`).
2. **PIN Generator Modal**: Tombol di dashboard admin `index.html` untuk men-generate PIN 6 digit dan menyalin template WhatsApp.
3. **Split Logic Controller**:
   - Modul Big Five & DISC (un-timed, auto-advance).
   - Modul Frexor / Cognitive (timer 45s, tab-switch watcher, copy-block).
4. **Live Synchronization**: Menulis hasil akhir langsung ke field `assessment` kandidat di database (`/talents/[id]/assessment`) agar Report Card & Pentagon Matrix terisi otomatis secara real-time.

---

## Not Doing (and Why)
- **Webcam Video Proctoring**: Memaksa akses kamera webcam sering kali gagal (*permission denied*) pada peramban mobile (Chrome/Safari HP), memakan kuota video kandidat, dan menimbulkan resistensi privasi. Cukup gunakan timer 45 detik + tab-switch detection yang 10x lebih efektif mencegah penggunaan AI.
- **Aplikasi Mobile Terpisah (APK/App Store)**: Memaksa kandidat mengunduh aplikasi terpisah menurunkan tingkat partisipasi hingga 70%. Web mobile instan berbasis browser adalah standar industri rekrutmen modern.
- **Login Akun dengan Password**: Mewajibkan registrasi akun baru membebani kandidat. 6-digit One-Time PIN jauh lebih cepat dan minim hambatan.
